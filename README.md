# Excel Strip to Value

Clean messy Excel financial reports: unmerge cells, remove rows/columns that are blank across the whole sheet, convert text-formatted numbers to real numbers with thousands-separator formatting, and resize columns to fit.

See [`excel_strip_to_value - Instruction.txt`](excel_strip_to_value%20-%20Instruction.txt) for setup and usage instructions.
